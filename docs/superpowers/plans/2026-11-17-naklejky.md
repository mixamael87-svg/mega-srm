# Наклейки — план реализации

> **For agentic workers:** REQUIRED SUB-SKILL: Use superpowers:subagent-driven-development (recommended) or superpowers:executing-plans to implement this plan task-by-task. Steps use checkbox (`- [ ]`) syntax for tracking.

**Goal:** Из видаткової накладної одной кнопкой на набор получить PDF наклеек 37,5 × 40 мм по артикулам и количествам накладной, с базой наклеек внутри MEGA SRM.

**Architecture:** Две новые таблицы (`LabelSet`, `Label`). Чистая функция `planLabels` превращает строки накладной + наклейки набора в список страниц и списки пропусков. `renderLabelsPdf` (pdfkit) рисует страницы: текст с автоподбором кегля, векторный EAN-13, знак відповідності. API: CRUD наклеек, импорт JSON, план/PDF печати по документу. UI: кнопки в «Історії», вкладка «Наклейки». База «Загальна» переносится из `.btw` (превью → OCR → проверка владельцем → импорт).

**Tech Stack:** Next.js 15, Prisma 6 / PostgreSQL, zod, vitest, Playwright, **pdfkit** (новая зависимость), шрифт **Liberation Sans Bold** (SIL OFL, файл в репо).

**Spec:** `docs/superpowers/specs/2026-11-17-naklejky-design.md` (в проекте — `claude/mega-srm-naklejky-design.md`).

## Global Constraints

- Размер страницы PDF: 37,5 × 40 мм = **106.30 × 113.39 pt**; одна наклейка на страницу; поля 1,5 мм (4.25 pt).
- Штрихкод: `ean13FromSku` из `src/domain/barcode.ts` (префикс `48260770`); при ручном вводе — 13 цифр с верной контрольной цифрой или пусто.
- `sku` наклейки — ровно 4 цифры или пусто (служебная, напр. «частина 2»); уникален в пределах набора.
- Печать — только `Document.type = NAKLADNA` и `status = ACTIVE`; иначе 409 `LABELS_NOT_ALLOWED`.
- Источник строк — последний `DocumentVersion.linesJson` документа (`DocLine[]`).
- `noPrint` и отсутствующие наклейки никогда не попадают в PDF.
- Наборы при миграции: «Загальна» (sort 1), «ФОП Кузнецов» (2), «ТОВ Кузкас» (3).
- Права: чтение/создание/правка/печать — любой вошедший; удаление наклейки и набора, импорт — `admin`.
- Тексты интерфейса и ошибок — украинский, как в остальном приложении.
- Push в `main` = выкладка на рабочий сайт — только по явному «отправляй» владельца.

## Review Focus

1. Строка накладной с артикулом не из 4 цифр (`id_2022`, пусто) → попадает в «Немає наклейки», печать не падает. (тест в Task 2)
2. Один артикул в нескольких строках (цвета после «Мікс») → количества суммируются в одну позицию. (Task 2)
3. Очень длинный текст → кегль не ниже 4 pt, текст не залезает на штрихкод; редактор показывает «Текст не вміщається». (Task 3, Task 6)
4. `extraLabel` удалён или помечен `noPrint` → основная наклейка печатается без второй, без ошибки. (Task 2, Task 4)
5. Анулированная накладная или рахунок → 409 `LABELS_NOT_ALLOWED`, кнопок в UI нет. (Task 5, Task 6)
