# Права менеджера: почти как у админа, без удаления — короткий дизайн

Дата: 2026-11-18 · Утверждено владельцем в чате

**Зачем:** владелец хочет, чтобы менеджеры могли почти всё, что админ, кроме удаления.

**Менеджерам открывается:** «Наші ФОП» — создание, правка (назва, реквизиты, телефон, «основний»), импорт из SalesDrive; пункт меню для всех. «Анулювати» документ (решение владельца).

**Остаётся только у admin:** удаление клиентов, ФОП клиентов и наших ФОП, в т. ч. скрытие нашего ФОП в архив и «Повернути» (`DELETE /api/fops/:id`, `PATCH /api/fops` с полем `archived`, `GET /api/fops/:id`); «Користувачі» (иначе менеджер может выдать себе admin и обойти запрет удаления).

**Подходы:** А ✅ — расширить права роли «менеджер»; Б — отдельная галочка-право на пользователя (отвергнуто: владелец хочет для всех менеджеров).
