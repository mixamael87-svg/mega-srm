# «Звіти клієнтів»: подсказка артикула по названию, правка артикула и цены в строке — короткий дизайн

Дата: 2026-11-19 · На утверждение владельцу

**Зачем:** владелец загрузил сначала остатки (без штрихкодов) — распознано 0 из 472. Хочет: система сама подбирает наш артикул по названию, рядом поле для ручной правки; цена — так же (подставлена и правится).

**Факт (проверка на реальных файлах Family Toys):** подбор по названию (сходство по триграммам с каталогом YML) угадывает 134 из 202 товаров (66 %); ошибки бывают и при высоком сходстве (0,82: «Качка» → «Кит»). Значит, подбор — только подсказка, которую человек подтверждает.

**Подходы:** А ✅ — одна таблица, у каждой строки поле «Артикул» с подставленным значением и цветом источника, подтверждение жёлтых; Б — оставить отдельный список «Не розпізнано», подсказку показывать только там (меньше правок, но владелец хочет править любую строку); В — автоматически принимать подсказки выше порога (быстро, но 0,82-ошибки попадут в документы — анти-цель).

**Как:**
- Строки таблицы — по коду клиента (+ цене), сумма по выбранному магазину/всем; документы группируют по нашему артикулу.
- Поле «Артикул» (редактируемое), источник цветом: 🟢 точно — наш штрихкод или сохранённый код клиента; 🟡 угадано по названию — рядом наше название и кнопка «✓»; ⚪ пусто — сходство < 0,35.
- Правка артикула (Enter/уход с поля) или «✓» сохраняет сопоставление для клиента (`ClientCode`, manual) → строка 🟢; «Підтвердити всі» — для всех жёлтых.
- «Нова ціна» сразу = «Ціна закупки» из отчёта, правится; кнопка «Заповнити старою ціною» убирается.
- Название в строке — наше из каталога по выбранному артикулу; нет в каталоге — название клиента «(з звіту)».
- Документы и Excel недоступны, пока есть ⚪ или 🟡 строки (подсказка: «Підтвердіть або виправте артикули: N»).

**Решения исполнителя:** порог подсказки 0,35 (ниже — пусто); подбор учитывает все товары каталога, при равенстве — товар «Мікс»; Excel тоже требует подтверждённых артикулов (чтобы файл не содержал угаданных).
